# MJM – portál nájemníků (zkušební verze)

Webová aplikace pro nájemníky MJM rodinná realitní a personální agentura s.r.o.

- `index.html` – celá aplikace (běží na GitHub Pages).
- `firestore.rules` – pravidla databáze Firebase. Vkládají se ručně ve Firebase → Firestore Database → Rules.

Osobní údaje nájemníků v tomto repozitáři nejsou. Jsou jen v databázi Firebase, kam je nahrává správkyně.
